## 项目通读（首次阅读本仓库）

- 仓库定位：AI 跨境电商运营智能体工具箱（MIT 开源，v0.4 / CHANGELOG 记到 v0.3）。不是软件产品，是「方法论 + Prompt + 确定性脚本 + 案例」的集合。
- 目标平台：Shopee 巴西 / Mercado Livre 巴西为一等支持（PT-BR 输出），Amazon / TikTok Shop / Shopify 仅字段适配。
- 结构：`SKILL.md` 为伞形入口（整个文件夹可整体装成一个 Skill），路由到 `Agents/01..07` 七个模块；每模块固定 `prompts/ + templates/ + examples/ + references/ + scripts/`。
- 七模块链路：01 市场分析 → 02 产品策略 → 03 Listing / 04 主图 / 05 视频 → 上架 → 06 广告诊断 + 07 评论分析 → 回流 03/04（闭环，一次只改一个病因）。
- 脚本层：10 个 Python 脚本共约 2700 行，纯标准库，均可独立运行（已验证 02 `sku_pricing.py`、01 `market_metrics.py`、03 `title_lint.py`、06 `ad_metrics.py` 的 CLI 正常）。设计原则「能算的别让模型猜」。
- 合规设计：原始 SOP PDF 含刷单/刷评/恶意举报/参数虚标等灰产做法，仓库全部移除并给出合规替代，见 `docs/03_Compliance_Guard.md`（R1-R6 硬拦截）与 `docs/05_SOP_Gap_Register.md`（只登记结论层级、不复述操作细节）。
- 关键约束：所有面向买家的文本必须是 PT-BR 母语；数值必须溯源到 `spec_table`；缺字段报 `[INPUT_MISSING]` 不许猜。
